# run_hani

3D 가상공간에서 강화학습 신경망으로 4족 로봇 "HANI"가 10m 달리기를 배우는 프로젝트입니다.

## 현재 상태: 1단계, 배경과 로봇 (신경망 없음)

- `models/hani_track.xml`: MuJoCo 모델 파일(MJCF)
  - 3레인 10m 트랙: 출발선 x=0, 결승선 x=10
  - 결승 게이트, 관중석, 광고판
  - 4족 로봇 HANI: 약 12.5kg, 관절 12개, 위치 제어 모터
  - 트랙과 경기장은 보이기만 하는 장식입니다. 물리 충돌은 바닥과 로봇만 계산하므로 같은 파일을 나중에 학습에도 그대로 씁니다.
- `index.html`, `web/main.js`: 브라우저 3D 뷰어
  - 물리 엔진: MuJoCo 공식 WebAssembly 패키지 `@mujoco/mujoco`
  - 화면 그리기: Three.js
  - 지금은 신경망 없이 모터가 서 있는 자세만 유지합니다.

## 실행 방법

ES 모듈과 모델 파일을 불러와야 하므로 로컬 웹 서버로 엽니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

| 키 | 동작 |
|---|---|
| R | 리셋 |
| M | 모터 켜기/끄기 (끄면 주저앉음) |
| P | 옆에서 밀기 |
| Space | 일시정지 |
| C | 카메라 전환: 추적 → 전체 → 자유 |
